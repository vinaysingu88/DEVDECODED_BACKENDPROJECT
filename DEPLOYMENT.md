# Backend deployment (Render + Aiven MySQL)

This directory is the complete backend deployment unit. For a backend-only GitHub repository, put the contents of this directory at the repository root. If deploying from the existing monorepo, configure Render's Root Directory as `DevDecoded_back`.

## 1. Create the Aiven MySQL service

Create a MySQL service in Aiven and note its database name, username, password, hostname, and port. Download the service CA certificate from Aiven. Keep these credentials and the certificate out of Git.

## 2. Deploy the backend to Render

Create a Render web service from the backend repository and use the included `render.yaml` (or these commands):

- Build: `pip install -r requirements.txt && python manage.py collectstatic --noinput`
- Start: `python manage.py migrate && gunicorn DevDecoded_back.wsgi:application --bind 0.0.0.0:$PORT`

Set `ALLOWED_HOSTS` to the Render API hostname (without `https://`). Set the `DATABASE_*` variables to the values from Aiven. Upload the downloaded Aiven CA certificate as a Render Secret File, then set `DATABASE_SSL_CA` to its mounted path (for example, `/etc/secrets/aiven-ca.pem`). `SECRET_KEY` is generated by the Render Blueprint. Keep `DEBUG` set to `False`.

Leave `CORS_ALLOWED_ORIGINS` empty until the React app has a deployed URL. Then set it to that exact origin, such as `https://your-frontend.onrender.com`, without a trailing slash.

After deployment, create an admin user from the Render Shell with `python manage.py createsuperuser` if you need Django admin access.

## 3. Push only this backend

Create an empty GitHub repository for the backend. From this directory, initialize Git and push this folder as the repository contents:

```powershell
git init -b main
git add .
git commit -m "Prepare Django backend for deployment"
git remote add origin <your-backend-repository-url>
git push -u origin main
```

The local `.env`, SQLite database, and collected static files are excluded by `.gitignore`.
